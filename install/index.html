安装为 App

The Optics Report 支持以 App 形式安装（PWA）。无需应用商店、不用注册，也不占多少空间，装好后可以从主屏幕或开始菜单一键打开。下面按设备和浏览器分别说明。

你现在已经是在 App 里打开本站了，无需再安装。

你的浏览器支持直接安装：

装好后有什么

  • 主屏幕 / 桌面图标，一键打开
  • 独立窗口，没有地址栏，看起来就像普通 App
  • 打开过的页面在没网时也能看（价格可能不是最新）
  • 每次联网打开都会自动更新，不用手动升级

iPhone / iPad · Safari

  1. 用 Safari 打开本站首页。
  2. 点底部（iPad 在顶部）的「分享」按钮（方框加向上箭头）。
  3. 往下滑，点「添加到主屏幕」。
  4. 确认名称后点右上角「添加」。
  5. iOS 16.4 及以上，在 Chrome、Edge 等浏览器里也能从「分享」菜单添加到主屏幕；更早的系统请用 Safari。

Android · Chrome

  1. 用 Chrome 打开本站。
  2. 如果底部弹出「安装应用」提示，直接点「安装」。
  3. 没有提示的话，点右上角 ⋮ 菜单 →「安装应用」（部分版本显示为「添加到主屏幕」）。
  4. 按提示确认，图标会出现在主屏幕和应用列表里。

Android · Samsung Internet / Edge

  1. 点底部或右上角的菜单（≡ 或 …）。
  2. 选「添加页面到」→「主屏幕」，或直接选「安装应用」/「添加到手机」。
  3. 确认即可。

Android · Firefox

  1. 点右上角 ⋮ 菜单。
  2. 选「添加到主屏幕」或「安装」。
  3. 确认后图标会出现在主屏幕上。

电脑 · Chrome / Edge（Windows、macOS、Linux、ChromeOS）

  1. 打开本站首页。
  2. 点地址栏右侧的安装图标（显示器加向下箭头，或带加号的小方框）。
  3. 也可以走菜单：Chrome 为 ⋮ →「投放、保存和分享」→「安装页面…」（旧版为「安装 The Optics Report…」）；Edge 为 … →「应用」→「将此站点作为应用安装」。
  4. 点「安装」。以后可以从开始菜单、程序坞或启动器打开。

Mac · Safari（macOS Sonoma 14 及以上）

  1. 用 Safari 打开本站。
  2. 菜单栏「文件」→「添加到程序坞」（或点工具栏的分享按钮 →「添加到程序坞」）。
  3. 点「添加」，图标会出现在程序坞和「应用程序」文件夹里。
  4. 更早的 macOS 不支持，请改用 Chrome 或 Edge。

电脑 · Firefox

  1. Firefox 桌面版目前还不能把网站装成 App。
  2. 可以把本站加入书签，或改用 Chrome / Edge 安装。

限制说明

  • 没有推送通知：本站是纯静态网站，没有服务器发送降价提醒。
  • 离线只能看你之前打开过的页面；没打开过的页面会显示离线提示。离线看到的价格和库存可能已过期，下单前请联网核对。
  • App 只是网站的另一种打开方式，不会收集额外数据；卸载方法和普通 App 一样（长按图标删除，或在浏览器的应用管理里卸载）。

安裝為 App

The Optics Report 支援以 App 形式安裝（PWA）。不需要應用程式商店、不用註冊，也幾乎不佔空間，裝好後可從主畫面或開始選單一鍵開啟。以下依裝置與瀏覽器分別說明。

你目前已是在 App 中開啟本站，不需要再安裝。

你的瀏覽器支援直接安裝：

裝好後有什麼

  • 主畫面／桌面圖示，一鍵開啟
  • 獨立視窗，沒有網址列，用起來就像一般 App
  • 開過的頁面在沒網路時也能瀏覽（價格可能不是最新）
  • 每次連網開啟都會自動更新，不必手動升級

iPhone / iPad · Safari

  1. 用 Safari 開啟本站首頁。
  2. 點下方（iPad 在上方）的「分享」按鈕（方框加向上箭頭）。
  3. 往下捲動，點「加入主畫面」。
  4. 確認名稱後點右上角「新增」。
  5. iOS 16.4 以上，在 Chrome、Edge 等瀏覽器中也能從「分享」選單加入主畫面；較舊的系統請使用 Safari。

Android · Chrome

  1. 用 Chrome 開啟本站。
  2. 若底部跳出「安裝應用程式」提示，直接點「安裝」。
  3. 若沒有提示，點右上角 ⋮ 選單 →「安裝應用程式」（部分版本顯示為「新增至主畫面」）。
  4. 依提示確認，圖示會出現在主畫面與應用程式清單中。

Android · Samsung Internet / Edge

  1. 點底部或右上角的選單（≡ 或 …）。
  2. 選「新增頁面至」→「主螢幕」，或直接選「安裝應用程式」／「新增至手機」。
  3. 確認即可。

Android · Firefox

  1. 點右上角 ⋮ 選單。
  2. 選「新增至主畫面」或「安裝」。
  3. 確認後圖示會出現在主畫面上。

電腦 · Chrome / Edge（Windows、macOS、Linux、ChromeOS）

  1. 開啟本站首頁。
  2. 點網址列右側的安裝圖示（螢幕加向下箭頭，或帶加號的小方框）。
  3. 也可以從選單操作：Chrome 為 ⋮ →「投放、儲存及分享」→「安裝網頁…」（舊版為「安裝 The Optics Report…」）；Edge 為 … →「應用程式」→「將此網站安裝為應用程式」。
  4. 點「安裝」。之後可從開始選單、Dock 或啟動器開啟。

Mac · Safari（macOS Sonoma 14 以上）

  1. 用 Safari 開啟本站。
  2. 選單列「檔案」→「加入 Dock」（或點工具列的分享按鈕 →「加入 Dock」）。
  3. 點「加入」，圖示會出現在 Dock 與「應用程式」檔案夾中。
  4. 較舊的 macOS 不支援，請改用 Chrome 或 Edge。

電腦 · Firefox

  1. Firefox 桌面版目前尚無法將網站安裝為 App。
  2. 可將本站加入書籤，或改用 Chrome／Edge 安裝。

限制說明

  • 沒有推播通知：本站是純靜態網站，沒有伺服器發送降價提醒。
  • 離線時只能瀏覽之前開過的頁面；沒開過的頁面會顯示離線提示。離線看到的價格與庫存可能已過期，下單前請連網確認。
  • App 只是網站的另一種開啟方式，不會收集額外資料；移除方式與一般 App 相同（長按圖示刪除，或在瀏覽器的應用程式管理中解除安裝）。

Install as an app

The Optics Report can be installed as an app (a PWA). There is no app store, no sign-up and almost no storage used; once installed, it opens in one tap from your home screen or Start menu. Pick your device and browser below.

You are already using the installed app — nothing more to do.

Your browser supports one-click install:

What you get

  • A home-screen / desktop icon that opens in one tap
  • Its own window with no address bar, like a regular app
  • Pages you have already opened still work offline (prices may be out of date)
  • Updates itself automatically whenever you open it online

iPhone / iPad · Safari

  1. Open the home page in Safari.
  2. Tap the Share button (a square with an up arrow) at the bottom of the screen — at the top on iPad.
  3. Scroll down and tap “Add to Home Screen”.
  4. Check the name, then tap “Add” in the top-right corner.
  5. On iOS 16.4 and later you can also do this from the Share menu in Chrome, Edge and other browsers; on older versions, use Safari.

Android · Chrome

  1. Open the site in Chrome.
  2. If an “Install app” prompt appears at the bottom, tap “Install”.
  3. If not, tap the ⋮ menu (top right) → “Install app” (on some versions: “Add to Home screen”).
  4. Confirm. The icon appears on your home screen and in your app drawer.

Android · Samsung Internet / Edge

  1. Tap the menu (≡ or …) at the bottom or top right.
  2. Choose “Add page to” → “Home screen”, or “Install app” / “Add to phone”.
  3. Confirm.

Android · Firefox

  1. Tap the ⋮ menu (top right).
  2. Choose “Add to Home screen” or “Install”.
  3. Confirm. The icon appears on your home screen.

Computer · Chrome / Edge (Windows, macOS, Linux, ChromeOS)

  1. Open the home page.
  2. Click the install icon at the right end of the address bar (a monitor with a down arrow, or a small box with a plus sign).
  3. Or use the menu — Chrome: ⋮ → “Cast, save, and share” → “Install page…” (older versions: “Install The Optics Report…”); Edge: … → “Apps” → “Install this site as an app”.
  4. Click “Install”. From then on, launch it from the Start menu, Dock or app launcher.

Mac · Safari (macOS Sonoma 14 or later)

  1. Open the site in Safari.
  2. Choose File → “Add to Dock” in the menu bar (or click the Share button in the toolbar → “Add to Dock”).
  3. Click “Add”. The icon appears in the Dock and in your Applications folder.
  4. Older macOS versions don’t support this — use Chrome or Edge instead.

Computer · Firefox

  1. Desktop Firefox can’t install websites as apps at the moment.
  2. Bookmark the site instead, or install it with Chrome or Edge.

Limitations

  • No push notifications: this is a static website with no server to send price alerts.
  • Offline, only pages you have already opened are available; anything else shows an offline notice. Offline prices and stock may be out of date — check online before you buy.
  • The app is just another way to open the website and collects no extra data. Remove it like any other app (long-press the icon, or uninstall it from your browser’s app settings).

Installer comme application

The Optics Report peut s’installer comme une application (PWA). Pas de boutique d’applications, pas d’inscription, presque aucun espace utilisé : une fois installée, elle s’ouvre d’un geste depuis l’écran d’accueil ou le menu Démarrer. Choisissez votre appareil et votre navigateur ci-dessous.

Vous utilisez déjà l’application installée — rien d’autre à faire.

Votre navigateur permet l’installation en un clic :

Ce que vous obtenez

  • Une icône sur l’écran d’accueil ou le bureau, qui s’ouvre d’un geste
  • Une fenêtre à part, sans barre d’adresse, comme une application ordinaire
  • Les pages déjà consultées restent lisibles hors ligne (les prix peuvent être périmés)
  • Mise à jour automatique à chaque ouverture en ligne

iPhone / iPad · Safari

  1. Ouvrez la page d’accueil dans Safari.
  2. Touchez le bouton Partager (un carré avec une flèche vers le haut), en bas de l’écran — en haut sur iPad.
  3. Faites défiler et touchez « Sur l’écran d’accueil ».
  4. Vérifiez le nom, puis touchez « Ajouter » en haut à droite.
  5. Depuis iOS 16.4, vous pouvez aussi le faire depuis le menu Partager de Chrome, Edge et d’autres navigateurs ; sur les versions antérieures, utilisez Safari.

Android · Chrome

  1. Ouvrez le site dans Chrome.
  2. Si le message « Installer l’application » apparaît en bas, touchez « Installer ».
  3. Sinon, touchez le menu ⋮ (en haut à droite) → « Installer l’application » (sur certaines versions : « Ajouter à l’écran d’accueil »).
  4. Confirmez. L’icône apparaît sur l’écran d’accueil et dans la liste des applications.

Android · Samsung Internet / Edge

  1. Touchez le menu (≡ ou …) en bas ou en haut à droite.
  2. Choisissez « Ajouter la page à » → « Écran d’accueil », ou « Installer l’application » / « Ajouter au téléphone ».
  3. Confirmez.

Android · Firefox

  1. Touchez le menu ⋮ (en haut à droite).
  2. Choisissez « Ajouter à l’écran d’accueil » ou « Installer ».
  3. Confirmez. L’icône apparaît sur l’écran d’accueil.

Ordinateur · Chrome / Edge (Windows, macOS, Linux, ChromeOS)

  1. Ouvrez la page d’accueil.
  2. Cliquez sur l’icône d’installation à droite de la barre d’adresse (un écran avec une flèche vers le bas, ou un petit carré avec un +).
  3. Ou passez par le menu — Chrome : ⋮ → « Caster, enregistrer et partager » → « Installer la page… » (anciennes versions : « Installer The Optics Report… ») ; Edge : … → « Applications » → « Installer ce site en tant qu’application ».
  4. Cliquez sur « Installer ». Ensuite, lancez-la depuis le menu Démarrer, le Dock ou le lanceur d’applications.

Mac · Safari (macOS Sonoma 14 ou plus récent)

  1. Ouvrez le site dans Safari.
  2. Choisissez Fichier → « Ajouter au Dock » dans la barre des menus (ou bouton Partager de la barre d’outils → « Ajouter au Dock »).
  3. Cliquez sur « Ajouter ». L’icône apparaît dans le Dock et dans le dossier Applications.
  4. Les versions plus anciennes de macOS ne le permettent pas : utilisez plutôt Chrome ou Edge.

Ordinateur · Firefox

  1. Firefox pour ordinateur ne permet pas encore d’installer un site comme application.
  2. Ajoutez plutôt le site à vos favoris, ou installez-le avec Chrome ou Edge.

Limites

  • Pas de notifications push : ce site est statique et n’a aucun serveur pour envoyer des alertes de prix.
  • Hors ligne, seules les pages déjà consultées sont disponibles ; les autres affichent un avis hors ligne. Les prix et stocks consultés hors ligne peuvent être périmés : vérifiez en ligne avant d’acheter.
  • L’application n’est qu’une autre façon d’ouvrir le site et ne collecte aucune donnée supplémentaire. Supprimez-la comme n’importe quelle application (appui long sur l’icône, ou désinstallation dans les réglages d’applications du navigateur).
